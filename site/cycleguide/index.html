サイクルガイド

自転車で走る人のそばで、進む先の見どころや天気の変化を声で伝える Android アプリです。走っている間は画面に何も出さず、操作も求めません。

主な機能

  • 進む先の見どころ: 進む方向の少し先にある寺社・史跡・公園・博物館などを、着く前に短く案内します
  • 止まったときの話と地図: 信号待ちや休憩のときに話し、見どころと走ってきた道を地図に出します。走り終えたあとは、前回の走行を地図で見返せます
  • 安全のための知らせ: 1 時間以内の雨や雷雨、日の入りが近いことを知らせます
  • 走り方: 街中をゆっくり走る「ポタリング」と、長い距離を走る「ロングライド」から選べます
  • チャンネル: 標準・歴史をたどる・しずかに から、語り手と話題を選べます

使うときに必要なもの

  • Android 端末と、位置情報の許可
  • 案内と話しかけは、設定なしで運営の AI を使えます（1 日の回数に上限があります）。生成AI サービスの API キーを持っていれば、設定の画面で切り替えられます

安全について

自転車を運転しながらスマートフォンを手に持って使うことや、画面を見続けることは、道路交通法で禁止されています。操作は止まってからにしてください。イヤホンは周りの音が聞こえる状態で使ってください。

プライバシー

アカウントの登録、利用状況の解析、広告はありません。運営の AI を使うときは、案内と話しかけに使う情報が運営の中継を通りますが、中継は内容を保存しません。詳しくはプライバシーポリシーをご覧ください。
