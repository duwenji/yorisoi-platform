## 目的・背景

開発者の要望（2026-11-28）: CycleGuide でも走行中に画面を出す選択肢がほしい。画面は SanpoGuide に合わせて統一したい。

今の CycleGuide は、走行中は画面を出さない（ECOSYSTEM E-23、CycleGuide S-1・AC-7）。走っている間は黒い画面に「走行中」と「長押しで終える」だけを出し、地図・話のカードは止まっているときだけ出す。画面の作りも SanpoGuide と違う。題名の欄・走り方とチャンネルの欄・余白のある地図・大きな始めるボタンという並びで、施設の帯・お知らせ・向きの切り替え・スポットの一覧がない。

道路交通法（第 71 条 5 の 5）は、自転車でも、スマートフォンを手に持って使うことと、取り付けた画面を注視することを禁じている。ハンドルに固定した画面をちらっと見ることは、カーナビと同じく禁じられていない。

## スコープ・非スコープ

スコープ:
- 走行中に画面を出す選択肢（出すもの・操作・画面を点けたままにすること・オンにするときの注意）
- CycleGuide のメイン画面を SanpoGuide にそろえること（止まっているとき・走っていないとき・走行中）
- そろえるために、SanpoGuide の画面の部品を platform に移すこと

非スコープ:
- SanpoGuide の画面の振る舞いを変えること
- CycleGuide の設定・履歴・チャンネルの画面をそろえること（必要になったら別に検討する）
- 走行中の声の案内の中身・間隔
- 画面のロック中に出すこと（ロックを解いてから走る）

## 決定

### 走行中の画面

| ID | 決定 | 理由 |
|---|---|---|
| D-1 | 設定に「走行中も画面を出す」を置く。既定はオフで、オフのときは今の黒い画面（「走行中」と長押しで終えることだけ）のまま | 画面を見ずに使うのがアプリの前提（E-23）。見たい人だけが選ぶ |
| D-2 | オンのとき走行中に出すのは、地図（進む向きを上にし、現在地を追う。走った道・施設までの線・見どころと施設の点）、話のカード（最新の話の文字と出典。場面の絵は出さない）、施設の帯（種類と距離）、行き先の表示（「トイレへ」）。出さないのは、写真・画像・きっかけのシートや全画面、お知らせ、右下のボタン、スポットの一覧を引き上げた状態、スポットのカード | 開発者の決定で、話のカードの文字も出す。写真・画像は見つめる時間が長くなる。お知らせとボタンは操作を求める |
| D-3 | 走行中の操作は、画面のどこでも 2 秒押し続けて走行を終えることだけ（S-2 のまま）。地図の拡大・移動、点・カード・帯を押すことは受け付けない。画面の下に「長押しで走行を終える」を小さく出す | 走りながらの操作をさせない。触れただけでは何も起きない |
| D-4 | オンで走行中は、アプリが前に出ている間、画面を点けたままにする。止まったとき・走行を終えたとき・オフのときは、端末の設定に戻す | 画面が消えると点け直す操作が要り、走りながらの操作になる（開発者の決定） |
| D-5 | オンにするとき、一度だけ注意を出す: 「スマートフォンはハンドルなどに固定してください。走りながら画面を見続けることは道路交通法で禁止されています。見るのは一目だけにし、操作は止まってからにしてください。」設定の説明に、電池の減りが早くなることも書く。走る前の注意（S-5、`Lines.SAFETY_NOTICE`）の「このアプリは画面を見ずに使えます」は残す | 手に持って使うこと・注視は禁止されている。固定して一目で見るのは禁じられていない |
| D-6 | 止まっているかどうか（`MotionState`）の見分けは今のまま使う。オンのときは、走行中と止まっているときで同じ画面の形のまま、D-2・D-3 の制限だけを入れ切りする | 走り出すたびに画面が切り替わると、見たいときに見つからない |

### 画面をそろえる

| ID | 決定 | 理由 |
|---|---|---|
| D-7 | CycleGuide のメイン画面を SanpoGuide と同じ形にする: 上のバー（チャンネルを選ぶ欄が題名、履歴・設定・︙）、画面いっぱいの地図、地図の上に話のカード・施設の帯・お知らせ、右下にマイク・向きの切り替え・現在地に戻るボタン、左下に行き先の表示、下にスポットの一覧のシート。走り方は︙と設定から変える | 2 本のアプリを同じ使い方にする（開発者の要望） |
| D-8 | CycleGuide にもスポットの一覧のシートを入れる。走行中は近い順の見どころ（色分けで絞れる）と、始める・終えるボタン（手袋でも押せる高さ 56dp）。見どころを押すと、地図でその点を大きくし、シートが今のスポットの情報（地図データの情報と、その走行で話したこと）に替わる。走っていないときは位置を使わないので（プライバシーポリシー 3）、一覧は出さず、前回の走行の地図（F-31）と「走り始めると近くの見どころが出ます」を出す | 開発者の決定。走っていないときに位置を取らない約束は変えない |
| D-9 | そろえる部品は platform に移し、両アプリで同じものを使う: 施設の帯・行き先の表示・向きの切り替えボタン・お知らせの欄・シートの持ち手（kit-geo の map か kit-ui）、話のカード（文字・出典・場面の絵の枠。アプリの型に依らない形にして kit-ui）、チャンネルを選ぶ欄（kit-channel か kit-ui）。SanpoGuide は振る舞いを変えずに移した部品に切り替える | 同じ画面を 2 回書かない。施設までの線（RouteKeeper）と同じ進め方 |
| D-10 | 両アプリにないものは足さない。CycleGuide のスポットのカードには AI の解説（SanpoGuide の「解説を聞く・読む」）を入れない。SanpoGuide に走り方の欄は足さない | アプリの機能の違いはそのまま |

## 検討した案

| 案 | 内容 | 採らなかった理由 |
|---|---|---|
| 走行中は地図だけ | 話のカード・施設の帯を出さない | 開発者の決定で、話のカードの文字も出す |
| 止まっているときと同じ画面を走行中も出す | 操作も写真も制限しない | 走りながらの操作・注視をさせてしまう（S-2、道路交通法） |
| 画面は端末の設定どおり消える | 点けたままにしない | 点け直す操作が走りながらになる |
| 走行中だけ別の画面（大きな文字の専用画面） | 地図を出さない案内の画面 | 同じ形のままにする方が見たいものを見つけやすい（D-6）。SanpoGuide とそろわない |

## 受入条件

1. AC-1（D-1）: 既定のまま走ると、走行中は今の黒い画面が出る（エミュレータ）
2. AC-2（D-2・D-3）: 設定でオンにして走ると、走行中に地図・話のカードの文字・施設の帯が出て、写真・お知らせ・右下のボタンは出ない。地図を動かそうとしても、カード・帯・点を押しても何も起きず、2 秒押し続けると走行が終わる（エミュレータ）
3. AC-3（D-4）: オンで走行中は、端末の画面消灯の時間を過ぎても画面が消えない。止まると端末の設定どおりに消える（エミュレータ）
4. AC-4（D-5）: オンにすると注意が一度だけ出て、二度目からは出ない
5. AC-5（D-7・D-8）: 止まっているときの CycleGuide の画面が、上のバー・地図の上の 3 つ・右下の 3 つのボタン・左下の行き先・下のシートの並びで SanpoGuide と同じになる。走っていないときは見どころの一覧を出さず、位置を取らない
6. AC-6（D-9）: SanpoGuide の画面が、部品を移す前と同じに見え、同じに動く（エミュレータで並べて確かめる）
7. AC-7: 実機でハンドルに固定して走り、一目で地図と話の文字が読めることを開発者が確かめる
