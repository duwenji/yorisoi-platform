# ウェブの除外リスト 運営の決まり

## 文書情報

| 項目 | 内容 |
|---|---|
| 文書ID | WEB-EXCLUSION |
| ドキュメント種別 | 運営の決まり |
| 対象 | アプリが話の準備で読むウェブのページから、運営が外すサイト・ページ（[ADR-AGENT](../../ADR-AGENT.md) A-24・A-25） |
| 公開 | アプリの「情報の出どころ」とチャンネル提供者の手引きからリンクする |

## 目的

アプリは、運営の出どころの台帳と、チャンネルが書いた出どころのページだけを読み、話の手がかりにします。信用できる出どころのサイトにも、話に向かないページや、あとで中身が変わったページがあります。運営は除外リストを持ち、そこに載ったサイト・ページを、どのチャンネルでも読みません。本書は、除外リストに足す・外す基準と、申し立ての受け方を決めます。

## 決まり

| ID | 項目 | 内容 |
|---|---|---|
| E-1 | 当て方 | 1 行は、ドメイン（下位のドメインも含む）か、URL の前方一致で当てる。行ごとに、種類・理由・きっかけ・足した日を残す |
| E-2 | 足す種類 | 次のどれかに当たるものだけを足す。① まとめ・アフィリエイト・量産記事 ② 口コミ・Q&A・掲示板・SNS・個人のブログの集まり ③ 誤情報・詐欺を知られたもの ④ 成人・賭け事・違法なもの ⑤ 事件・事故・ゴシップが中心のもの ⑥ AI で作った記事の量産 ⑦ 利用者の知らせで誤りが続いたもの ⑧ 話に向かないページ（入札・採用・手続き・議事録など。出どころのサイトの中のパスに当てる） ⑨ サイトの運営者から読み取りをやめてほしいと申し立てがあったもの |
| E-3 | 足さないもの | 意見や立場が運営と違うだけのもの、競合する事業者のもの、批判的な内容のものは、E-2 に当たらない限り足さない |
| E-4 | 候補の集め方 | 次のきっかけで候補を集め、運営が見て足す。候補のまま自動で足すことはしない。① 利用者の知らせ（同じドメイン・同じパスの数） ② 2 つ以上のチャンネルの `skip` に書かれたもの ③ 開発者の記録で、誤った手がかりに使われたページ ④ 読んでも手がかりが 0 のことが続くパス |
| E-5 | 急ぎ | 詐欺・違法なもの、危ない場所へ誘う手がかり、出どころのサイトの乗っ取りが分かったときは、運営がすぐに足して公開する |
| E-6 | 公開 | 公開するたびに版を 1 つ上げる。アプリは 1 日 1 回と、散歩・走行を始めたとき（前に取ってから 6 時間を過ぎていれば）に取り直す |
| E-7 | 外す | 種類に当たらなくなった（サイトが変わった・誤って足した）と運営が確かめたら外す。⑦ は、足してから 90 日たち、知らせが続いていなければ見直す |
| E-8 | 申し立て | サイトの運営者からの、外してほしい・読まないでほしいという申し立ては、権利の申し立てと同じ窓口（[channel-review](../../../policies/channel-review.md)「権利の申し立て」）で受ける。運営は 14 日のうちに見て、結果を知らせる。読まないでほしいという申し立ては、確かめたうえで ⑨ として足し、台帳からも外す |
| E-9 | チャンネルの除外との関係 | チャンネルの `skip` は、そのチャンネルでだけ足す。除外リストを減らすことはできない |
| E-10 | 記録 | 足す・外す・直すたびに、だれがいつ何をしたかを運営の画面に残す。種類ごとの行の数は、年に 1 回まとめて公開する |
