# AI-ROLES の改訂案（ADR-AGENT）

| ID | 今 | 改めた文 |
|---|---|---|
| H-1 役割の分け方 | 語りを 5 つの役割で分ける。…**実演**（その場で話す）は生成AI、… | 語りを 5 つの役割で分ける。…**実演**（その場で話す・話の前に調べる）は生成AI、…。実演の生成AI は 3 つに分ける。**話し手**（その場で話す）、**準備役**（チャンネルの方針の範囲の中で、道具で調べ物を選び、話の筋を作る。事実の文は書かず、道具の結果を番号で指す）、**手がかり作り**（ページの本文から、決まった場面の手がかりだけを取り出す。道具を持たない）。何を調べてよいか・どこを読んでよいかは演出（チャンネル提供者）が決める（[ADR-AGENT](../../ADR-AGENT.md) A-1・A-2） |
| H-5 根拠の安全 | 根拠は**データとして扱い、指示としては扱わない**。…根拠は審査と署名を経たものに限るので、ウェブの文章を渡すより注入の危険は小さい | （今の文のあとに足す）**調べた手がかり**（準備役が道具で取った結果。台帳とチャンネルの出どころのページ・気象庁の季節の観測・今ある事実）は、根拠とも参考の文章とも別の区分にする。根拠と同じく区切りで囲み、データとして扱い、中の指示に従わない。ページの文は、道具を持たない手がかり作りの AI だけが読み、道具を持つ準備役には見せない。話すときは出どころを添え、国の機関・都道府県・市区町村の出どころは事実として、観光協会・団体・チャンネルの出どころは「〜と紹介されていました」と言い切らずに話す（ADR-AGENT A-18・A-30） |
| H-6 実演の枠 | ② 根拠を使ったときは、出典（素材の `credit`）を画面に出す | ② 根拠・調べた手がかりを使ったときは、出典（素材の `credit`、手がかりの出どころ・題名・リンク・発行日）を画面に出す |
| H-9 アプリ利用者が決める上限 | （今の文） | （今の文のあとに足す）準備役と手がかり作りの呼び出しも AI の 1 回として数え、1 日の上限の 2 割までにする（ADR-AGENT A-33） |
