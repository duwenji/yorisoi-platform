# channel-review の改訂案（ADR-AGENT）

| 節 | 足す・改める文 |
|---|---|
| 1. 機械で確かめる項目 | 箇条に足す: 「`agent` の値が決まった選択肢の中にあり、`paths` が `scenes` の場面だけでできている。`sources` の URL が `https://` で、運営の除外リストに当たらない」 |
| 2.2 安全 | 足す: 「`agent.sources` のサイトが、チャンネル提供者自身のサイトか公の出どころ（国の機関・都道府県・市区町村・観光協会・団体）のページで、宣伝・口コミ・まとめが中心でない。共用のサービス（ブログ・ホームページ作成）の上のサイトは、チャンネル提供者のものであることを確かめる」 |
| 2.3 プライバシー | 足す: 「`agent.topics` に、個人を特定できる言葉・住所・連絡先を含めない」 |
| 2.5 AI への指示の書き方 | 足す: 「準備役には `companion/topics` がデータとして渡る。`companion/topics` に、調べ物を指示する文（「〇〇のサイトを読め」など）を書かない。調べてよい範囲は `agent` の項目で書く」 |
| 2.7 話させた見本の確認 | 表に足す: 「`agent.mode` が `plan` のチャンネル: 見本の市区町村 3 つ（都市・郊外・いなか）と審査の日で準備役を動かし、筋と、その筋で話した雑談の見本を確かめる（ADR-AGENT A-54）。筋の出どころが `sources` と台帳の範囲に収まり、宣伝・事件・個人の話が出ないこと」 |
| 3. 判定 | 足す: 「`sources` のサイトが基準に当たらないときは、その出どころを外すよう求める（チャンネル全体は差し戻さない）」 |
