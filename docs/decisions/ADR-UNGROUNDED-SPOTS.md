## 目的・背景

開発者の要望（2026-11-28）: 地元住民向けのチャンネル（yorisoi-channel-local の北綾瀬の近所歩き）をエミュレータで確かめたところ、根拠のない寺社で、見ていないようすや人のようすを作って話した。

| 場所 | 話した内容 | 根拠 |
|---|---|---|
| 法立寺（解説） | 「静かにお参りしていく人が多い場所です」「境内では、石の文化財や木々の様子を」 | 地図データの名前と種類だけ |
| 法立寺（チャンネルの指示を直したあと） | 「木々のあいだの参道がしっとり落ち着いて見えますね」「門の前でちょっと足を止めるだけでも」 | 同上 |
| 水神宮（解説） | 「名前のとおり水の神さまをまつる社で」「ふと手を合わせていく人が多い場所です」 | 同上 |
| 法立寺・水神宮（続き） | 「散歩のついでに門だけ眺めて歩くのも楽しいですよ」「いくつか寄り道しながら歩いてみるのもいいですよ」 | なし |

固定部分の指示が食い違っている。`shared/facts` は「見ていないもの・人の様子を想像で話さない」と言う一方で、次の指示が話を埋めるよう求めている。

- `shared/speech`（SanpoGuide）:「知らないこと・資料にないことをわざわざ断らない。言えることだけを話し、**目の前に見えるものや、その場での楽しみ方に話をつなぐ**」
- `guide/system` の事実の扱い:「詳しいことがないときは、名前と種類を伝え、**その種類の場所の一般的な楽しみ方**（SanpoGuide は**季節・天気に合う感想**も）を短く添える」
- `guide/system` の続き:「本文と違う切り口の余談（**その種類の場所の楽しみ方・寄り道の勧めなど**）」

AI はこれらに従い、「一般的な楽しみ方」を「この場所の人のようす・見た目」として話す。チャンネルの指示（`guide/focus`）で止めても、別の言い方で出てくる。チャンネルを問わず起きるので、固定部分で直す。

## スコープ・非スコープ

スコープ:

- 両アプリのスポット解説（本文と続き）と再訪の一言で、根拠に詳しいことがないときの話し方
- アプリの組み込みのチャンネルのスロット
- `shared/speech` の「話をつなぐ」の部分

非スコープ:

- 「分かりません」と断らない決まり（今のまま残す）
- 第三者のチャンネルのスロット（審査基準の「事実を作らない指示になっているか」で見る）
- 雑談（`companion/system`）。近くの場所は名前・種別・距離・方角だけと、すでに決まっている（REQ-NEARBY-TALK）
- 雑談で天気・時間帯の感想を繰り返すこと（別の原因。同じ確認で見つかった）
- 根拠があるスポットの話し方

## 決定

| ID | 決定 | 理由 |
|---|---|---|
| U-1 | タグ・地図データの情報・資料・調べた手がかりに詳しいことがないスポットは、名前と種類（寺・神社・公園など）を 1〜2 文で伝えて終える。解説の長さ（`guide.length`・CycleGuide の字数）に届かなくてよい | 長さを埋めようとして作る。短く終えれば作る余地がない |
| U-2 | U-1 のとき、見た目（門・参道・木・石など）・人のようす（お参りする人・にぎわい）・その種類の場所の一般的な楽しみ方・季節や天気の感想を足さない。名前の字から、まつるもの・由来・役目を推し量らない | 「一般的な楽しみ方」が「この場所のようす」として話される。季節・天気の感想は雑談が受け持つ |
| U-3 | 「分かりません」「資料がありません」のように断らない決まりは残す | 断る言い方は散歩の雰囲気に合わない（2026-10-19 の決定）。U-1 で短く終えれば、断る必要もない |
| U-4 | 解説の続きは、本文で言わなかった、タグ・地図データの情報・資料・調べた手がかりから言えることだけにする。言えることがなければ書かない（0〜2 つ）。「楽しみ方・寄り道の勧め」の例を外す | 続きは根拠のない余談になりやすい。続きがなければ、次の合間は取り置いた雑談か新しい雑談になる（F-14） |
| U-5 | `shared/speech` の「目の前に見えるものや、その場での楽しみ方に話をつなぐ」を外し、「言えることだけを話す」で終える（CycleGuide と同じ形） | `shared/facts` と食い違う |
| U-7 | アプリの組み込みのチャンネルの `guide/focus` も合わせる。「情報が少ない場合は、楽しみ方・観察のヒント・昔の役割・見どころを話す」を「名前と種類だけを短く伝える」にする（SanpoGuide の 5 つ）。「立ち寄るとしたら何が楽しめるか」は根拠にあるときだけにする（CycleGuide の標準）。再訪の一言（SanpoGuide `companion/events/revisit`）の「前回とは違う楽しみ方」も外す | チャンネルのスロットが固定部分と逆の指示をすると、固定部分を直しても埋める話が残る |
| U-6 | 両アプリで同じにする。プロンプトの版を上げて公開し、validator を新しい版にして配備する | 固定部分は両アプリの決まり（AI-ROLES H-6） |

## 検討した案

| 案 | 内容 | 採らなかった理由 |
|---|---|---|
| A: 断らない決まりを消す | `shared/speech` の「わざわざ断らない」を消す | 作り話の元は「話をつなぐ」「楽しみ方を添える」の指示で、残る。「詳しいことは分かりませんが」の前置きが戻る |
| C: チャンネルで選べるようにする | 観光向けは今のまま、地元向けだけ短くする設定を `channel.json` に足す | 作り話はチャンネルを問わず誤り。設定と契約（API-CHANNEL-PACKAGE）の変更が要る |
| チャンネルの指示だけで止める | `guide/focus` に禁止を足す | 試した（北綾瀬、2026-11-28）。法立寺は減ったが、水神宮で同じ形が出た |

## 受入条件

1. AC-1（U-1・U-2）: エミュレータで北綾瀬の法立寺・水神宮のように根拠のないスポットを通ると、解説は名前と種類の 1〜2 文で終わり、見た目・人のようす・楽しみ方・名前からの推し量りが出ない
2. AC-2（U-3）: 同じ確認で、「分かりません」「資料がありません」のような断りが出ない
3. AC-3（U-4）: 根拠のないスポットで続きが 0 になっても、次の合間に雑談が出る（テスト）
4. AC-4: 根拠のあるスポット（浅草界隈ガイドの浅草寺など、北綾瀬の龍慶寺）の解説の長さと中身が変わらない
5. AC-5（U-6）: validator の準拠テストが通る
