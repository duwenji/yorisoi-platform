# 意思決定記録

## 文書の呼び方

このリポジトリでは canonical ID を使います。履歴・既存の外部資料に旧番号が出てくる場合は、上の一覧で読み替えてください。別のリポジトリの番号付き文書を指す場合は、リポジトリ名を併記します。
