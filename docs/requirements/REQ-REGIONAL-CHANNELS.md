## 目的・背景

第三者のチャンネルには、浅草界隈ガイドのように、特定の地域を案内するものがあります（以下「地域のチャンネル」）。チャンネル提供者は申請のときに地域（geohash の接頭辞、8 個まで）を書き、運営のリスト（API-CHANNEL-LIST）の `channels[].regions` に載ります。今のアプリは、これを一覧の並び順に使うだけです。

散策者は、地域のチャンネルがあることを知らなければ使えません。リストを足していても、設定の奥のチャンネルの一覧を開かなければ気づきません。本書は、地域のチャンネルの地域に入ったとき、チャンネルの選択の先頭に出し、一度だけ知らせる要件です。

## スコープ・非スコープ

### スコープ
- 今いる地域に合う地域のチャンネルを、端末の中でリストから見つける（位置を外へ送らない）
- チャンネルの選択の先頭に「この地域のチャンネル」として出す。取り込んでいないものも出し、その場で取り込める
- 散歩・走行の始め、または途中で地域に入ったとき、一度だけ画面と声で知らせる
- 知らせを止める設定
- 審査基準に、申請の地域の確かめ方を足す。提供者の手引きに、知らせに使われる地域の書き方を足す

### 非スコープ
- 地域に入ったら自動でチャンネルを切り替えること（開発者の決定。利用者が選ぶ）
- 地域から出たときに元のチャンネルに戻す知らせ
- リストを足していない運営のチャンネルを知らせること（足したリストだけが対象）
- 組み込みのチャンネル（地域を持たない）
- 地域を geohash 以外の形（多角形など）で書くこと
- iOS

## 方針・決定事項

| No. | 決定 | 理由 |
|---|---|---|
| D-1 | 今いる位置の geohash が、チャンネルの `regions` のどれかで始まるとき、そのチャンネルを「この地域のチャンネル」とする。照合は端末の中で、取得済みのリストだけで行う | 位置を外へ送らない（API-CHANNEL-LIST「位置情報」）。リストにはすでに `regions` が載っている |
| D-2 | チャンネルの選択の先頭に「この地域のチャンネル」の欄を置く。取り込んでいないものも出し、選ぶと今の取り込みの確かめ（AI の費用の目安）を経て使える | 開発者の決定（2026-11-26）。設定の奥の一覧を開かなくても見つけられる |
| D-3 | 知らせは、チャンネルごとに 1 日 1 回まで。散歩・走行の始めにすでに地域の中なら始めに、途中で入ったらそのときに、画面（カード）と声で 1 回知らせる。今そのチャンネルを使っているときは知らせない | 開発者の決定（2026-11-26）。何度も出すと、案内の邪魔になる |
| D-4 | 切り替えは利用者が選ぶ。自動では切り替えない | 開発者の決定（2026-11-26）。チャンネルを選ぶのは利用者（AI-ROLES の分担） |
| D-5 | `channels[].regions` の意味を「並び順」から「並び順と、選択の先頭・知らせ」に広げる。地域の外でも今どおり使える | 形式（項目）を変えずに済む。今のリスト・アプリと互換 |
| D-6 | 知らせに使うのは、5 文字以上（およそ 5 km 四方以下）の接頭辞だけ。4 文字以下の地域は、選択の先頭には出すが知らせない | 申請の地域は 1〜8 文字で書ける。短い接頭辞（県より広い）で知らせると、地域のチャンネルとして意味がなく、遠くでも知らせてしまう |
| D-7 | 候補は、アプリの過ごし方（`walk`・`cycle`）に合うものだけ。試用中のチャンネル（試用チケット）は、知らせの対象にしない（選択には今どおり出る） | 合わない過ごし方のチャンネルは使えない（API-CHANNEL-PACKAGE G-4）。試用は提供者が自分で選んで試すもの |
| D-8 | 複数の地域のチャンネルが合うときは、接頭辞の長い（狭い地域の）ものから並べる。知らせは 1 回に 1 つ（いちばん狭い地域のもの）だけ話し、ほかは「ほかに〇つあります」と添える | 狭い地域ほど、その場所に合った案内 |
| D-9 | 知らせの文はアプリの固定の文（AI を使わない）。チャンネルの名前と、選び方（「チャンネルの選択から使えます」）だけを言う | AI の回数を使わない。宣伝の文を提供者に書かせない |
| D-10 | 知らせの声の優先度は、天気の急変・日の入り・施設の案内より低く、スポットの解説・雑談より高い。CycleGuide では走行中の安全の決まり（信号の近く・速いときは黙る）に従い、止まったときに回す | 安全の案内を邪魔しない。地域に入った直後に知らせたい |
| D-11 | 設定に「地域のチャンネルを知らせる」（既定はオン）を置く。オフでも、選択の先頭には出す | 知らせが要らない人がいる。選択の先頭は邪魔にならない |
| D-12 | 言語（REQ-LANGUAGES）: アプリの言語に対応していないチャンネルも出し、「日本語のみ」などの印を付ける | REQ-LANGUAGES D-8 と同じ |

## 機能要件

### 見つける（platform kit-channel）
| ID | 要件 |
|---|---|
| F-1 | 位置が更新されるたび（散歩・走行中）と、アプリを開いたとき、今いる位置の geohash（8 文字）と、足したリストの `channels[].regions` を照らし、この地域のチャンネルを求める（D-1）。過ごし方に合わないもの・取り下げられたものは除く（D-7） |
| F-2 | 求めた結果は、接頭辞の長い順に並べる（D-8）。それぞれに、知らせに使えるか（5 文字以上の接頭辞で合ったか。D-6）を持つ |
| F-3 | 両アプリで同じ部品を使う |

### 選択の先頭（両アプリ）
| ID | 要件 |
|---|---|
| F-4 | チャンネルの選択（SanpoGuide のメイン画面の選択、CycleGuide の選択）の先頭に「この地域のチャンネル」の欄を置き、F-1 で求めたチャンネルを並べる。欄は合うものがなければ出さない |
| F-5 | 取り込んでいないチャンネルは「取り込んで使う」として出し、選ぶと今の取り込みの確かめ（AI の費用の目安。API-CHANNEL-LIST）を出す。確かめたら取り込んで切り替える |
| F-6 | 取り込み済みのチャンネルは、選ぶとすぐ切り替える（今の選択と同じ） |
| F-7 | アプリの言語に対応していないチャンネルには印を付ける（D-12、REQ-LANGUAGES F-23） |

### 知らせ（両アプリ）
| ID | 要件 |
|---|---|
| F-8 | 散歩・走行を始めたとき、知らせに使える地域のチャンネル（F-2）があり、今そのチャンネルを使っていなければ、知らせを出す（D-3）。途中で新しく地域に入ったときも同じ |
| F-9 | 知らせは、カード（「この地域には『浅草界隈ガイド』のチャンネルがあります。チャンネルの選択から使えます」）と、同じ文の読み上げ。カードを押すとチャンネルの選択を開く。ほかにも合うものがあれば「ほかに〇つあります」と添える（D-8・D-9） |
| F-10 | 同じチャンネルの知らせは、その端末で 1 日 1 回まで（日付は端末の日付）。知らせたチャンネルを記録し、翌日にまた知らせてよい |
| F-11 | 知らせの声は D-10 の優先度で出す。CycleGuide では黙る条件の間は待ち、止まったときに出す。散歩・走行の終わりまでに出せなければ出さない |
| F-12 | 設定「地域のチャンネルを知らせる」がオフなら、F-8〜F-11 をしない（D-11） |
| F-13 | 知らせたことを、開発者モードの記録に残す（チャンネル・合った接頭辞・出したとき・出せなかった理由） |

### 審査・手引き
| ID | 要件 |
|---|---|
| F-14 | 審査基準に、申請の地域が、チャンネルが案内する場所に合っていて、広すぎないかを確かめる項目を足す（例: 浅草を案内するのに、東京都全体の接頭辞を書かない） |
| F-15 | 提供者の手引き（申請の地域の欄）に、知らせに使われるのは 5 文字以上の接頭辞だけであること、地域の決め方（案内する場所を覆う 5〜6 文字の接頭辞を並べる）を書く |
| F-16 | API-CHANNEL-LIST の `channels[].regions` の説明を、D-5 の意味に直す |

## 非機能要件
| ID | 要件 |
|---|---|
| N-1 | プライバシー: 照合は端末の中だけで行い、位置・照合の結果を外へ送らない。取り込んでいないチャンネルを候補に出すために、新しく取りに行かない（取得済みのリストだけを使う） |
| N-2 | 電池: 照合は位置の更新に乗せ、新しく位置を取らない。照合は文字列の前方一致だけ |
| N-3 | 邪魔にならない: 知らせは 1 日にチャンネルごと 1 回。散歩・走行の始めの知らせは、開始のあいさつのあとに出す |

## 受入条件
1. AC-1（F-1・F-4・F-5）: 浅草界隈ガイドの地域（例 `xn77h`）を持つリストを足し、エミュレータで浅草寺の近くにいると、SanpoGuide のチャンネルの選択の先頭に「この地域のチャンネル」として出る。取り込んでいなければ、選ぶと費用の目安が出て、確かめると使える
2. AC-2（F-8・F-9・F-10）: その地域の外から散歩を始めて地域に入ると、カードと声で一度知らせる。同じ日にもう一度入っても知らせない。翌日はまた知らせる
3. AC-3（F-8）: 地域の中で散歩を始めると、開始のあいさつのあとに知らせる。すでにそのチャンネルを使っていれば知らせない
4. AC-4（F-11）: CycleGuide で地域に入ったとき、信号の近くや速いときは待ち、止まったときに知らせる
5. AC-5（D-6）: 4 文字以下の接頭辞だけのチャンネルは、選択の先頭には出るが知らせない
6. AC-6（F-12）: 設定でオフにすると知らせないが、選択の先頭には出る
7. AC-7（D-7）: `walk` だけのチャンネルは、CycleGuide の選択にも知らせにも出ない
8. AC-8（N-1）: 照合の前後で、アプリが外へ送るものが増えていない（リストの取得のほかに要求がない）

## 用語定義
| 用語 | 意味 |
|---|---|
| 地域のチャンネル | リストの `channels[].regions` を持つチャンネル |
| この地域のチャンネル | 今いる位置の geohash が、`regions` のどれかで始まる地域のチャンネル（F-1） |
| 知らせ | 地域に入ったときに一度出すカードと読み上げ（F-8〜F-11） |

## 制約
- 地域は、申請のときに提供者が書いた geohash の接頭辞（1〜8 文字、8 個まで）。運営が審査で確かめる（F-14）
- 位置の精度（数十 m）のため、地域の境目では入ったり出たりが起きうる。知らせは 1 日 1 回なので繰り返さない
