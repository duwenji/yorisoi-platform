## 目的・背景

[提供価値と事業の検討](../overview/value-proposition.md) の V-5 は、場所と時間を限った情報を、その付近にいる人に届ける案です。最大の課題は、同じ場所・同じ時間に人がそろわないことでした。本書はそこに、アプリ利用者が声で残す短い文、**一言**を置きます。期限まで置き、後からその場所に来た人に届くので、時間をずらしても届き、人が少なくても成り立ちます（検討文書の段階 3）。

一言は素材の種類の 1 つで、チャンネルが出し方を決めます（[ADR-MATERIALS](../decisions/ADR-MATERIALS.md) D-2・D-37）。一言はアプリ利用者の投稿で、中身の責任は置いた人が持ちます。

一言は AI の語りの根拠にしません。語り手が出どころを紹介してから、そのまま読み上げます。だれが言ったかの責任を AI の語りと混ぜないためです。自由な会話（チャット）は作りません。

本書の範囲は、人がそろうか（検討文書の H-1・H-5）を確かめる前の最初の版に絞ります。一言は文字だけにし、届け方は区画ごとに数分おきに取る形にします。画像・声そのもの・映像と即時の配信は、使われ方を見てから足します（U-10）。運営が当面 1 人で、確認の手間と費用が、受け付ける形式の数だけ増えるからです。即時の配信は、同じ区画に同時に人がいるときにしか役に立ちません。

## スコープ・非スコープ

### スコープ
- 一言を置く（声を端末で文字にする、期限を選ぶ、AI による確認）
- 一言の置き場（期限まで保存）と、近くに来た人への配信（区画ごとの取得）
- チャンネルによる出し方（きっかけ・前置き）
- 読み上げの順番と上限、決まった反応、聞いた人数の概数
- 通報、自動で隠す、運営による削除と締め出し、ブロック
- 置き場と配信のサーバー（yorisoi-console に置く）と、アプリの共通の部品（platform）
- SanpoGuide と CycleGuide の画面と設定

### 非スコープ
- 招いた人だけのグループ（検討文書の段階 2）
- 一言への返信、自由な会話
- 一言の画像・声そのもの・映像、即時の配信（U-10）
- 一言を AI の語りの根拠にすること（D-10）
- SanpoGuide と CycleGuide で一言を分けるか（U-6。分けないものとして書く）
- iOS

## 方針・決定事項

### 届け方

| No. | 決定 | 理由 |
|---|---|---|
| D-1 | アプリ利用者が置く短い文を **一言**、残した人を **置いた人**、届いた人を **聞いた人** と呼ぶ | 素材の種類の名前（ADR-MATERIALS D-52） |
| D-7 | 置き場と配信は yorisoi-console のスタックに置く（区画ごとに運営から取る素材の配信。ADR-MATERIALS D-44・D-51）。一言の文字は DynamoDB に期限まで置く（期限が来たら消す）。区画（geohash6、約 1.2 km × 0.6 km）ごとに取る API を出す。即時の配信は作らない（U-10） | 後から来た人に届けるには保存が要る。中継と同じ CDK・AWS アカウントで運用できる。FCM は使わない（API-SECRET-MESSAGES D-3） |
| D-8 | アプリは散歩・走行の間、今いる区画（geohash6）と周りの 8 区画の一言を取る。区画を移ったときと、5 分おきに取り直す。近づいたか（一言の区画とその周り）は端末で判定する | サーバーに渡す位置を約 1 km の粒度に抑える（API-SECRET-MESSAGES と同じ考え方） |
| D-9 | 聞いた数は、端末が「読み上げた」とだけ送って数える（一言の ID だけ。位置は送らない）。置いた人には 3 以上のときだけ概数で見せる | 少ない数は、聞いた人の居場所の手がかりになる |
| D-10 | 一言は AI の語りの根拠にしない。語り手が出どころを紹介して、そのまま読み上げる（「この辺りを通った人の一言です。」）。語り手が話していれば話し終えてから読む。AI の語りの呼び出し回数（ADR-AI-RELAY R-2）には数えない（ADR-MATERIALS D-38） | 人の言葉を AI の言葉として事実にしない |
| D-12 | 一言を聞くかを、設定で選ぶ（設定は素材の種類ごと。ADR-MATERIALS D-37）。初めて使うとき、知らない人の一言が読み上げられることを説明し、聞くかを選ばせる（説明の前は聞かない） | 何が耳に入るかを、本人が承知してから始める |
| D-13 | CycleGuide の走行中は、文字の読み上げだけ。一言を置く・反応・通報・ブロックは止まっているときだけ（REQ-CYCLEGUIDE S-2）。SanpoGuide では歩きながら置ける | 自転車の操作中に画面を見せない |
| D-21 | 読み上げは、1 時間に 10 件まで。同じ一言は 1 回だけ。語りと語りの間にだけ入れる。上限はアプリ全体で数え、チャンネルが緩めることはできない | 多すぎると、語りの体験が壊れる |
| D-25 | 一言を出すかどうか・いつ・どのように出すかは、チャンネルが決める（ADR-MATERIALS D-37・D-45〜D-49）。チャンネルが決められるのは、出すか、きっかけ（語りの合間 `idle`、スポット、地点）、前置き。一言を書いていないチャンネルは、語りの合間に出す。アプリ利用者の設定（D-12）は絞るだけで、チャンネルが出さない一言を出すことはしない | 選んだチャンネルの体験をまとめる。安全・上限・出どころ・本人の意思はチャンネルに任せない |

### 置く人と中身

| No. | 決定 | 理由 |
|---|---|---|
| D-2 | アプリ利用者ならだれでも一言を置ける。名前は出さず、置いた人は運営の AI の中継と同じインストール ID でだけ区別し、サーバーには HMAC で持つ（ADR-MATERIALS D-42）。事前の審査はしない | 運営は当面 1 人で、事前の審査は回らない。名前を出さないと、置いた人の居場所と人が結び付かない |
| D-3 | 一言は文字 60 字まで。声で話し、端末で文字にして、文字だけを送る。画像・音声・映像は付けられない（U-10） | 文字は確認が速くて安い。声は本人を特定できる。画像は、顔や位置の埋め込み情報の確認が要る |
| D-4 | 一言の場所は、置いたときの位置を約 150 m 四方の区画（geohash7）に丸めて持つ。近くのスポットの名前を 1 つ付けてよい。正確な座標は送らない | 一言が指す場所が分かれば足りる。置いた人の居場所を細かく残さない |
| D-5 | 一言の期限は、置いた人が 1 時間・24 時間・7 日から選ぶ（既定は 24 時間） | 「今」の情報と「この場所」の情報の両方に使える。古い一言を残さない |
| D-6 | 一言は、置く前に確かめる。文字は運営の AI で、①URL・電話番号・メールアドレス（ADR-AI-ROLES H-6 ③と同じ）、②安全を損なう誘い（私有地・線路・立入禁止の場所に入らせるなど）、③人や店を攻撃する言葉・個人を特定する情報、④宣伝・勧誘を判定する。どれかに当たれば置かず、置いた人にだけ「置けませんでした」と知らせる | 知らない人に読み上げるので、置いたあとでは遅い。一言はアプリ利用者の投稿で、宣伝の場ではない |
| D-11 | 一言の中身は置いた人が受け持つ。運営は、通報と自動の判定（D-6）で守り、問題のある一言を消し、置いた端末を締め出す（ADR-MATERIALS D-41） | 置いた人は根拠・演出・実演・枠・考査のどれにも当たらないので、人の発言の層として分ける |
| D-15 | 決まった反応は、聞いた一言への「いいね」の 1 つだけ。置いた人には、いいねの数を D-9 と同じく概数で見せる | 置いた人に届いたことが伝わり、返信の会話にはならない |
| D-24 | 一言を初めて置く前に、利用規約（置いてはいけない一言、消すことと締め出し、置いた人の責任）への同意を求める。聞いた人は、聞いた一言の置いた人を「ブロック」でき、以後その人の一言は届かない。区画の一覧には置いた人を表す値を入れず、ブロックと自分の一言の判定はサーバーで行う（ADR-MATERIALS D-43） | Google Play のユーザー生成コンテンツのポリシー（利用規約の同意、アプリ内の通報、ユーザーのブロック）に合わせる。一覧に置いた人の値があると、同じ人の一言を場所をまたいでつなげられる |

## 機能要件

### 一言を置く
| ID | 要件 |
|---|---|
| F-1 | アプリ利用者は、ボタンを押して話すと一言を置ける。端末で文字にし、送る前に文字を見て、期限（D-5）・スポットの名前を付けるかを決められる。既定のまま 3 秒たつと送る |
| F-2 | 60 字を超えた一言は送れない。端末での文字起こしが使えない端末では、一言を置く機能を出さない（U-4） |
| F-3 | 一言は、置く前に D-6 の確認を通す。止めた一言は置かず、置いた人に知らせる |
| F-4 | 1 台の端末が置ける一言は 1 日 10 件まで。1 つの区画（geohash7）に同時に置かれる一言は 20 件まで。超えたら、期限の近い順に古いものから届けない |
| F-5 | 置いた人は、自分の一言を一覧で見られ、期限の前に消せる。一覧には、残りの時間と、聞いた人・いいねの概数（D-9・D-15）を出す |
| F-22 | 一言を初めて置く前に利用規約を見せ、同意した人だけが置ける（D-24） |

### 届ける・聞く
| ID | 要件 |
|---|---|
| F-6 | 散歩・走行の間、D-8 のとおり近くの一言を取る。散歩・走行をしていないときは取らない |
| F-7 | チャンネルのきっかけ（D-25）が来たら、そのきっかけの区画とその周りの一言から選び、D-10 のとおり読み上げる。チャンネルが選んだ前置きがあれば、出どころの紹介の前に読む。画面には、その散歩・走行で聞いた一言を出す |
| F-8 | 同じ一言は 1 回だけ読み上げる。自分が置いた一言は読み上げない |
| F-9 | 読み上げの上限は D-21 のとおり。超えたら、いいねの多いもの・新しいものを先にする |
| F-10 | 聞いた人は、聞いた一言に「いいね」を送れる（D-15） |
| F-11 | 一言を聞くかを、設定で選べる（D-12）。切ったら取らず、読み上げない |

### 通報と運営の操作
| ID | 要件 |
|---|---|
| F-12 | 聞いた人は、一言ごとに通報できる。通報はアプリからサーバーに送り、一言の ID と通報の種類だけを持つ（位置は入れない） |
| F-13 | 3 台以上の端末から通報された一言は、運営が確かめるまで、だれにも届けない |
| F-14 | 運営は、管理システムで通報された一言を見て、消すか戻すかを決められる。消した一言を置いた端末を、一言を置けないように締め出せる（期間を決める） |
| F-15 | 運営は、区画を指定して一言を置けないようにできる（学校・病院・私有地の周りなど） |
| F-23 | 聞いた人は、聞いた一言から置いた人をブロックできる。ブロックは一言の ID をサーバーに送り、サーバーは以後その人の一言を一覧から外す。ブロックは設定で解ける（D-24） |

| N-4 | 速さ: 一言の確認は、置いてから 5 秒以内に結果を返す（通信が普通のとき）。置いた一言は、同じ区画の端末が次に取り直したとき（5 分以内）に届く |
| N-5 | 費用: 一言の確認（運営の AI）は ADR-AI-RELAY R-10 の月の予算に含めて足し上げる。予算で中継が止まっている間は、一言を置けない（聞くことはできる） |
| N-6 | 通信: 区画の一覧の取得は 1 回 50 件まで（区画の一覧全体の数。API-LOCAL-MATERIALS）。区画を移ったとき以外は 5 分に 1 回まで取り直す |
| N-7 | 電池: 一言を取っている間の電池の減りを、散歩・走行だけのときと比べて記録する（目標は U-7） |

## 受入条件

1. AC-1（F-1・F-3）: 端末 A で一言を置くと、確認を通り、自分の一言の一覧に残りの時間とともに出る
2. AC-2（F-3・D-6）: 試験用の文の一覧のうち、URL・電話番号・安全を損なう誘い・攻撃・宣伝を含む文は置けず、「置けませんでした」と出る。普通の文（一覧の残り）は置ける。止めた割合と通した割合を記録する
4. AC-4（F-6・F-7・N-4）: 端末 B が同じ区画を散歩しているとき、端末 A が一言を置くと、5 分以内に端末 B で語りの合間に「この辺りを通った人の一言です。」に続けて読み上げる
5. AC-5（F-7・D-5）: 端末 A が 24 時間の一言を置いたあと、12 時間後に端末 B がその区画を通ると読み上げる。25 時間後に通ると読み上げない
6. AC-6（F-8）: 端末 B が同じ一言の区画を 2 回通っても、読み上げるのは 1 回。端末 A は自分の一言を読み上げない
7. AC-7（F-4・F-9・D-21）: 1 台の端末から 11 件目の一言は置けない。1 時間に一言の 11 件目は読み上げない
8. AC-8（D-9・D-15）: 聞いた端末が 2 台のとき、置いた人の一覧に数は出ない。3 台になると「3 人以上」と出る
12. AC-12（F-13・F-14）: 3 台の端末から通報された一言は、ほかの端末に届かなくなる。運営が管理システムで戻すと、また届く。消して置いた端末を締め出すと、その端末は一言を置けない
13. AC-13（F-15）: 運営が置けないようにした区画では、一言は置けないと出る
14. AC-14（F-11・D-12）: 初めての説明で一言を聞かないを選ぶと、一言は取らず読み上げない。ほかの種類の素材の設定には響かない
15. AC-15（F-16）: CycleGuide の走行中は、一言を置く・いいね・通報・ブロックができない。止まるとできる。走行中も一言の文字は読み上げる
16. AC-16（N-1・N-2）: 通信の記録で、送っている項目が N-1 のものだけである。サーバーのログに一言の本文と区画がない。期限の過ぎた一言がサーバーに残っていない
17. AC-17（F-22・F-23・D-24）: 利用規約に同意するまで一言を置く画面に進めない。端末 B が端末 A の一言からブロックすると、端末 A の別の一言は端末 B が取る一覧に入らない。ブロックを解くとまた届く。区画の一覧に、置いた人を表す値が入っていない
18. AC-18（F-7・D-25）: チャンネルが一言を出さないと書くと、設定で聞くにしていても読み上げない。一言を書いていないチャンネルでは、語りの合間に読み上げる

## 用語定義

| 用語 | 定義 |
|---|---|
| 一言 | 素材の種類の 1 つ。アプリ利用者が声で話し、端末で文字にした 60 字までの文。区画と期限を持ち、置いた人の責任で置く |
| 置いた人 | 一言を残したアプリ利用者。名前は出さない |
| 聞いた人 | 一言が読み上げられたアプリ利用者 |
| 区画 | 位置を丸めた格子。一言の場所は geohash7（約 150 m 四方）、取るときは geohash6（約 1.2 km × 0.6 km） |

## 制約

- 運営は当面 1 人（ADR-CHANNELS C-10）。一言は事前の審査をせず、AI の確認・通報・自動で隠す仕組みで守る
- 運営の AI は Bedrock を東京で使う（ADR-AI-RELAY R-5）。一言の確認も同じ形にする
- FCM の中継サーバーは運営しない（API-SECRET-MESSAGES D-3）。取るのは散歩・走行のサービスが動いている間だけ
- 端末での文字起こしは、端末の中で処理できる音声認識（Android 12 以上）を使う（U-4）

| 電気通信事業法（届出） | 不特定多数が文字を交わす「場」を提供する電子掲示板は、他人の通信を媒介しないので、届出の要らない電気通信事業（第三号事業）。届出が要るのは、利用者登録が必要で前年度の月間アクティブ利用者数の平均が 1,000 万以上のときと、サービスの一部として利用者間のメッセージを媒介するとき（電気通信事業参入マニュアル［追補版］p.27「電子掲示板」、p.4「媒介相当電気通信役務」） | 届出は要らない。一言への返信や個別のやり取り（非スコープ）を足すと届出が要るので、足すときは改めて確かめる |
| 情報流通プラットフォーム対処法（特定電気通信による情報の流通によって発生する権利侵害等への対処に関する法律） | 開示を求められる発信者情報は、「当該特定電気通信役務提供者が保有する」もの（第 5 条第 1 項） | 出せるのはサーバーにある情報だけで、そのために新しく集めない（ADR-MATERIALS D-42）。大規模な事業者の義務（削除の基準の公表など）は、総務大臣が指定した事業者に限られる |
| 景品表示法（ステルスマーケティングの告示、令和 5 年内閣府告示第 19 号） | 告示の対象は、事業者の表示なのに第三者の表示のように見えるもの（「一般消費者が事業者の表示であることを判別することが困難である表示」の運用基準 第 2） | 店の人が客を装って一言で宣伝するのは告示の対象になりうるので、置く前の確認（D-6 ④）と通報で止める |
