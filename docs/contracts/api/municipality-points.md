# 市区町村の代表点の配信ファイル

[AGENT](../../overview/agent.md) A-14 のとおり、アプリは今いる市区町村を端末の中で決める。そのための点の表を、運営のタイルのバッチが作り、スポットのタイルと同じ配信で配る。読み取りは kit-geo の `Municipalities`。

## 形

- 都道府県ごとに 1 つの CSV（UTF-8、改行は LF）。名前は `municipality-points/{都道府県の番号 2 桁}.csv`
- 1 行目は見出し `code,name,lat,lon`。2 行目から 1 行 1 点
- 点は、国土交通省の位置参照情報（大字・町丁目レベル）の代表点。同じ市区町村の点が何行も続く

| 列 | 中身 |
|---|---|
| `code` | 全国地方公共団体コード（6 桁） |
| `name` | 都道府県名と市区町村名（例: `福井県福井市`）。政令市は区まで（例: `北海道札幌市中央区`） |
| `lat`・`lon` | 代表点の緯度・経度（世界測地系、小数 5 桁まで） |

## 都道府県の索引

同じ場所に `municipality-points/index.json` を置く。都道府県ごとの範囲（南・西・北・東の緯度経度）で、代表点の範囲に 5 km（0.05 度）の余白を足したもの。アプリは今の位置が入る都道府県（境のあたりでは 2〜3 つ）の CSV だけを取る。

```json
{"version":1,"prefectures":{"01":[41.3,139.3,45.6,145.9],"18":[35.3,135.4,36.35,136.9]}}
```

47 都道府県すべてを作れた週だけ作り直す。1 つでも作れなければ前の週の索引がまるごと残る。読み取りは kit-geo の `Municipalities.prefecturesAt`。

## 使い方

アプリは、今の位置にいちばん近い点の市区町村を使う。5 km 以内に点がなければ、市区町村は分からないとする。位置は端末の外に出さず、準備役には市区町村の名前だけを渡す。

## 出典

位置参照情報は国土交通省のデータで、出典を示して使う。アプリの「情報の出どころ」に「位置参照情報（国土交通省）を加工して作成」と書く。
