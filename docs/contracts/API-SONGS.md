## 文書情報
| 項目 | 内容 |
|---|---|

| ドキュメント種別 | API 契約書（配信の形式と、アプリの取り方） |
| 対象システム/機能 | 運営が配る季節の歌（著作権の切れた唱歌・童謡のメロディ）の一覧と音。yorisoi-console（作り方と配信）、platform（取る部品）、yorisoi-sanpoguide・yorisoi-cycleguide（流す） |

## 目的・背景

[REQ-NEARBY-TALK](../requirements/REQ-NEARBY-TALK.md) の季節の歌（F-21〜F-27・F-33・F-34、D-12〜D-15）を、アプリに入れずに運営の配信から届けるための形を決めます。アプリは、曲の一覧を取り、今の季節と次の季節の曲を前もって端末に残し、散歩・走行の雑談の話題の 1 つとして流します。

## スコープ・非スコープ

### スコープ
- 配信の URL・HTTP の応答・一覧（`catalog.json`）の形・音のファイルの形
- 曲の作り方（開発者の音符から音を作り、配信に上げる）と、権利の確かめの記録
- アプリの取り方・残し方・選び方の決まり

### 非スコープ
- 曲を流すときの判定（雑談の話題に選ぶ・止める・音量）。REQ-NEARBY-TALK F-23〜F-27 と各アプリの設計で決める
- 歌声・歌詞、チャンネル提供者が出す歌（REQ-NEARBY-TALK 非スコープ）
- 本番の配信（開発用のあと、スポットのタイルの本番と同じ時期に）

| S-3 | 最初の版は 15 曲。春: 春が来た・春の小川・花、夏: 夏は来ぬ・茶摘み・我は海の子、秋: もみじ・赤とんぼ・蟲のこゑ・うさぎ、冬: 雪・冬景色・冬の夜、通年: 故郷・七つの子。我は海の子・冬景色・冬の夜はスキャンから読み取る。権利は作るときに曲ごとに確かめる | 開発者の決定（2026-11-09。各季節 3 曲以上・通年 2 曲）。REQ-NEARBY-TALK F-21 |
| S-4 | 音は運営が作った演奏で、CC BY-SA 4.0 で配る。表示は「演奏: yorisoi 運営。楽譜: Wikipedia 日本語版（CC BY-SA 4.0）ほか」とし、曲ごとに楽譜の出どころを一覧に書く。曲そのもの（作詞・作曲）はパブリックドメイン | 開発者の決定（2026-11-09）。Wikipedia の記事は CC BY-SA 4.0 で、メロディを書き写しただけの楽譜に権利が生まれるかは微妙なので、安全側に倒して同じライセンスで配る。録音は借りないので、録音の権利の問題は起きない |

## エンドポイント一覧

| メソッド | パス | 内容 |
|---|---|---|
| GET | `/songs/v1/catalog.json` | 曲の一覧 |
| GET | `/songs/v1/audio/{file}` | 1 曲の音。`{file}` は一覧の `songs[].file` |

## リクエスト・レスポンス仕様

### HTTP の応答

| 応答 | 意味 | アプリの扱い |
|---|---|---|
| 200 | 本文あり。`catalog.json` は `Content-Type: application/json`・gzip、音は `audio/mp4`。どちらも `ETag` あり | 一覧は置き換える。音は残す |
| 304 | `If-None-Match` の ETag と同じ | 残しているものをそのまま使う |
| 403・404 | ない | 一覧なら歌を使わない（F-34）。音ならその曲を選ばない |
| 5xx・通信の失敗 | 取れない | 残しているものがあれば使う。なければ歌を使わない |

キャッシュ: `catalog.json` は `Cache-Control: max-age=3600`。音は名前に中身のハッシュが入るので `max-age=31536000, immutable`。

リクエストに付けてよいのは、`User-Agent`（アプリ名と版）と `If-None-Match` だけです。位置・利用者を表すものは送りません（N-6）。

### catalog.json

```json
{
  "format": "yorisoi-songs",
  "version": 1,
  "updatedAt": "2026-11-10T00:00:00Z",
  "credit": "演奏: yorisoi 運営（CC BY-SA 4.0）。楽譜: Wikipedia 日本語版（CC BY-SA 4.0）ほか。曲はパブリックドメインです。",
  "songs": [
    {
      "id": "momiji",
      "title": "紅葉",
      "seasons": ["autumn"],
      "timesOfDay": ["day", "evening"],
      "weather": [],
      "durationSec": 48,
      "file": "momiji-3f9a1c2b.m4a",
      "bytes": 391204,
      "sha256": "3f9a1c2b…",
      "rights": {
        "lyricist": { "name": "高野辰之", "died": 1947 },
        "composer": { "name": "岡野貞一", "died": 1941 },
        "score": "尋常小学唱歌 第二学年用（1911）",
        "notesFrom": { "title": "もみじ (曲) - Wikipedia", "url": "https://ja.wikipedia.org/w/index.php?title=…&oldid=…", "license": "CC BY-SA 4.0" },
        "checkedAt": "2026-11-10",
        "checkedBy": "duwenji"
      }
    }
  ]
}
```

| 項目 | 型 | 必須 | 内容 |
|---|---|---|---|
| `format`・`version` | string・number | ○ | `yorisoi-songs`・`1`。違えばアプリは一覧を使わない |
| `updatedAt` | string | ○ | 一覧を作った日時（ISO 8601） |
| `credit` | string | ○ | 「このアプリについて」に出す一文（N-7） |
| `songs[].id` | string | ○ | 曲の ID。`^[a-z0-9-]{2,40}$`。前回・今回流した曲を覚えるのに使う |
| `songs[].title` | string | ○ | 題名。前置き（F-24）と「このアプリについて」に使う |
| `songs[].seasons` | string[] | ○ | `spring`・`summer`・`autumn`・`winter`・`all` の 1 つ以上 |
| `songs[].timesOfDay` | string[] | ○（空でもよい） | 合う時間帯。`morning`・`day`・`evening`・`night`。空ならどの時間帯でも |
| `songs[].weather` | string[] | ○（空でもよい） | 合う天気。`clear`・`cloudy`・`rain`・`snow`。空ならどの天気でも |
| `songs[].durationSec` | number | ○ | 長さ（30〜60） |
| `songs[].file`・`bytes`・`sha256` | string・number・string | ○ | 音のファイル名・大きさ（1 MB 以下）・中身の SHA-256（16 進） |
| `songs[].rights` | object | ○ | 作詞者・作曲者（`name`・`died`。作者不詳なら `name` は「不詳（文部省唱歌）」、`died` は null）、初出の楽譜（`score`）、音符を取った先（`notesFrom`: 題名・版を指す URL・ライセンス）、確かめた日と人（D-14） |

アプリは、知らない項目を無視します。`seasons`・`timesOfDay`・`weather` の知らない値も無視します（その値がないものとして扱う）。

### 音のファイル

- AAC（M4A）、モノラル、64 kbps、44.1 kHz、30〜60 秒、1 MB 以下
- 始めと終わりに 0.5 秒のフェード。音量はおおむね -20 LUFS にそろえる（読み上げより小さめ。F-22）
- メタデータに題名と「演奏: yorisoi 運営（CC BY-SA 4.0）」を入れる

## 曲の作り方

yorisoi-console の `songs/` に置きます。週ごとのタイルの作り直しとは別に、曲を足したときだけ開発者が手元で動かします。

| 段 | 内容 |
|---|---|
| 1. 音符 | `songs/scores/{id}.ly` に LilyPond でメロディだけを置く。Wikipedia から取った曲は記事の版（`oldid`）を、スキャンから読み取った曲は元のスキャンを、ファイルの頭に書く。原曲（初出の楽譜）と照らし、今の編曲は使わない（R-6） |
| 2. 一覧の元 | `songs/catalog.yaml` に、題名・季節・時間帯・天気・権利（作詞者・作曲者と亡くなった年・元にした楽譜・確かめた日と人）を書く |
| 3. 確かめ | 道具が、作詞者・作曲者の亡くなった年が 1967 年以前（または作者不詳の文部省唱歌）か、長さ・大きさが範囲内かを確かめる。外れたら止まる（D-14） |
| 4. 音にする | 道具が LilyPond で MIDI にし（Docker）、音符を数式の音色で鳴らし（S-5）、ffmpeg で M4A にする（Docker） |
| 5. 上げる | `songs/v1/audio/` に音を上げ、最後に `catalog.json` を上げる。一覧から消えた曲の音は消す。CloudFront の `/songs/v1/catalog.json` を無効化する |

## アプリの取り方

| No. | 決まり |
|---|---|
| AS-1 | 一覧は 1 日 1 回、散歩・走行をしていないときに取り直す（`If-None-Match`）。散歩・走行の最中は取らない（F-33・F-34） |
| AS-2 | 音は、従量制でないネットワーク（Wi-Fi など）のとき、今の季節と次の季節（と `all`）の曲を前もって取る。取ったら `sha256` を確かめ、合わなければ捨てる |
| AS-3 | 端末に残す音は合わせて 10 MB まで。超えたら、今の季節でも次の季節でもない曲から消す。一覧から消えた曲の音も消す |
| AS-4 | 流す曲は、端末に音がある曲から選ぶ（F-34）。季節が合う（`all` を含む）曲だけ。時間帯・天気が書いてあれば合うものを先にする。前回と今回の散歩・走行で流した曲は選ばない（F-23） |
| AS-5 | 季節は端末の日付で決める。3〜5 月 春、6〜8 月 夏、9〜11 月 秋、12〜2 月 冬（アプリの雰囲気・話しかけの季節と同じ） |
| AS-6 | 「このアプリについて」に、一覧の `credit` と、曲ごとの題名・作詞者・作曲者を出す（N-7） |
| AS-7 | 取る部品は platform に置き（新しいモジュール `kit-songs`）、両アプリで使う。流す・止めるのは各アプリ |

## エラー表

| 場面 | 扱い |
|---|---|
| 一覧の形が違う（`format`・`version`、必須の項目がない） | その一覧を使わない。前に残した一覧があれば使う |
| 1 曲の項目がおかしい（`seasons` が空、`bytes` が 1 MB を超える など） | その曲だけ使わない |
| 音の `sha256` が合わない | その音を捨て、次の先読みで取り直す |
| 一覧も音も一度も取れていない | 歌を使わない（雑談の話題からも外す） |

## 確認観点

| ID | 観点 |
|---|---|
| CK-1 | 道具が、亡くなった年が 1968 年以後の作者の曲を止める |
| CK-2 | 上げた `catalog.json` と音が、本書の形と応答（ETag・304・`Content-Type`・キャッシュ）どおりに返る |
| CK-3 | アプリが、散歩・走行の最中に一覧も音も取らない。Wi-Fi でないときは音を取らない |
| CK-4 | `sha256` が合わない音を使わない。10 MB を超えて残さない |
| CK-5 | 機内モードでも、残した音で歌が流れる（REQ-NEARBY-TALK AC-16） |

## 互換性方針・移行メモ

- 形を変える（項目の意味を変える・必須を足す）ときは `version` を上げ、パスを `songs/v2/` にする。古いアプリは `v1` を使い続ける
- 任意の項目・列挙の値を足すのは、版を上げずにできる（アプリは知らないものを無視する）

## 制約

- 曲は 15 曲から始め、多くても 100 曲までとする（一覧を 1 つの JSON で取るため）
- 開発用だけ。本番の配信は、スポットのタイルの本番と同じ時期

## 未決事項・リスク

| ID | 内容 | 対応 |
|---|---|---|
| R-1 | 数式の音色が単調で、聴き続けると機械っぽい | 倍音と揺らぎを足した音色を数種類用意し、曲ごとに選ぶ。開発者が耳で確かめる |
| R-2 | 音符の写し違い（Wikipedia の楽譜の誤り、スキャンの読み違い） | 作った音を開発者が初出の楽譜と照らして聴く（S-2）。`checkedBy` に残す |
| R-3 | スポットのタイルの配信を止めると、歌も止まる | 同じスタックなので、止めるときは両方の影響を考える。分けたくなったら別のスタックに移す（URL の基点を変えるだけ） |
